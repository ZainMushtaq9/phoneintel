Username checking needs the Python app.
Checking whether a username exists on another site requires reading that site's HTTP response — and browsers block cross-site response checks (CORS), so a static page cannot do this check honestly. Run the Flask app in this repo (python app.py) and use its Username Tracker tab instead — it checks 19 sites from the server side.

Phone analysis is 100% in-browser — it uses only the public numbering-plan data bundled with the google-libphonenumber library. IP lookups use the free ipwho.is API. This tool does not track live locations, check accounts on other services, or extract phone numbers from social media.

Static-version limits: carrier lookup is not included in the JavaScript library (use the Python/Flask app in this repo for carrier data); timezones are an approximate region-level mapping, not a per-number lookup; location is country-level only; username checking is not possible from a static page (see the Username Tracker tab). The full investigation report and PDF export also need the Python backend.
