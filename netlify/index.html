100% in-browser — analysis uses only the public numbering-plan data bundled with the google-libphonenumber library. This tool does not track live locations or check accounts on other services.

Static-version limits: carrier lookup is not included in the JavaScript library (use the Python/Flask app in this repo for carrier data); timezones are an approximate region-level mapping, not a per-number lookup; location is country-level only.
