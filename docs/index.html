    PhoneIntel provides privacy-respecting phone-number analysis. It does not identify private social-media accounts, enumerate registrations or access restricted personal information. This site runs on GitHub Pages; the investigation API runs on a Cloudflare Worker (free tier) using public numbering-plan data, the free ipwho.is API, OVH's public API, and status-only username checks. If the API is unreachable, phone analysis falls back to running offline in your browser — the page always says which mode it is in.
